---
name: write-page
description: "Crear o corregir contenido en ChatGPT Pages o Spaces cuando el usuario solicite guardar el resultado allí."
---

Usa las herramientas de Pages disponibles en el entorno. Lee la Page y la secuencia actual antes de editar, y aplica una modificación concreta preservando bloques, adjuntos y metadatos. Verifica el resultado con una lectura posterior.

Si faltan las herramientas de Pages, prepara el contenido para revisión y explica que aún no se guardó en una Page. No simules IDs ni enlaces. Una Page visible no equivale por sí sola a una orden de editarla.

Consulta [compatibilidad cloud](../../cloud/COMPATIBILITY.md) si faltan herramientas o dependencias.
